Privacy policy

Last updated: September 25, 2026

The integration is in setup and is not currently connected to Pinterest. This page describes its current status and intended operation.

Who operates it

Vee, the owner of @anvikv24, operates this personal research project. It serves only its owner; it does not accept registrations or account connections from other people.

This website

These information pages have no forms, analytics scripts, advertising pixels or application cookies. They do not receive Pinterest passwords, tokens or research results. If hosted on GitHub Pages, GitHub processes visitor information according to its privacy statement.

Intended data access and use

If Pinterest approves the integration, the owner would authorize permitted trend and keyword research through Pinterest's official authentication flow. Requests may contain keywords, regions and date filters. Results would be used to answer the owner's research questions in Codex. Access to other users' private accounts is outside this project's scope.

Service providers

Pinterest would receive API requests and supply authorized results. OpenAI would process information sent to Codex under the owner's applicable account settings and OpenAI's privacy policy. This project does not sell data or make research results available to other users.

Storage and controls

The project currently has no connected Pinterest data store. The permitted handling of results, Codex history and provider retention must be verified against Pinterest's requirements before activation. This policy does not promise that processing in Codex is temporary or that providers retain no logs.

Credentials must stay out of this website and public source files. The owner can disable the Codex connection and use Pinterest's authorization controls to stop future access. Removing a connection does not automatically delete information already retained by a provider; the owner's separate provider controls apply.

Questions and changes

The owner is identified by the Pinterest profile linked above. There is no public customer service or data-submission feature. This page will be updated before any material change to the stated scope or data handling.
